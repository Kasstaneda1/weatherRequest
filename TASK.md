# Задание: Weather App

## Что должно быть на странице

1. Страница содержит:
   - заголовок «Weather app»
   - поле для ввода города
   - кнопку «Search»
   - область для отображения данных о погоде или ошибки

2. При нажатии на кнопку отправляется запрос на адрес:

   ```
   https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${APP_ID}
   ```

3. Пока идёт запрос, показываем индикатор загрузки: кнопка «Search» становится неактивной, под формой появляется слово «Loading…». Данные предыдущего ответа при этом прячем.

4. Когда данные успешно пришли, показываем их на странице (как в макете).

5. Если пришла ошибка, вместо данных о погоде показываем её код и сообщение.

6. Если поле ввода пустое и человек нажал кнопку, показываем `alert` с просьбой ввести название города.

7. Макет в Figma:

   https://www.figma.com/design/fwgYIR4OoE2eC3UGw5ZUWD/Untitled?node-id=298-36&t=XuZXvaSdNoDTykhD-0

8. Иконку погоды берём из ответа API, картинка лежит по адресу:

   ```
   http://openweathermap.org/img/w/${icon}.png
   ```

## Примечания

В исходном тексте задания кнопка в одном месте названа «Search», а в другом «Получить погоду». Это одна и та же кнопка. На странице пишем на ней **Search**, как указано в первом пункте.

`APP_ID` это ключ от OpenWeather. Как с ним работать, написано в [README.md](README.md).
